# Celestial Ranger — iPhone App Prototype

Portfolio-ready interactive prototype based on the original Celestial Ranger HTML experience.

## Run locally
Because the app uses a service worker, serve this folder over HTTP:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Test
- Complete onboarding
- Explore the map
- Visit booths and collect stamps
- Try discovery challenges
- Write a field note
- Use the chat/story experience
- Check Eco Ranger progress
- Open More for the certificate/reset flow

## Portfolio framing
This is an installable PWA prototype with an iOS-style mobile shell. It is designed to be tested interactively without requiring a backend.

Note: the original experience labels park maps/routes, orders, and activity as simulated/unofficial, and that framing is preserved.
Deploy full-stack app.
